# intent-classification-ml
Text-based customer intent classification using TF-IDF and Logistic Regression.

# Customer Intent Classification Using Machine Learning

## Project Overview
This project predicts the intent behind customer messages using
Natural Language Processing (NLP) and Machine Learning.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- TF-IDF Vectorization
- Logistic Regression
- GridSearchCV
- Matplotlib
- Joblib

## Workflow
1. Load and merge datasets
2. Clean and preprocess text data
3. Split data into training and testing sets
4. Convert text into numerical features using TF-IDF
5. Train and tune a Logistic Regression model
6. Evaluate accuracy, precision, recall, and F1-score
7. Visualize the confusion matrix
8. Predict intents for new customer messages

## How to Run
Install dependencies:

pip install -r requirements.txt

Run the project:

python intent_classifier.py
